## 🎯 Что это

**RuLoad** — это бесплатная программа для Windows, которая устанавливает
российские приложения на iPhone через USB-кабель. Просто, быстро, без джейлбрейка.

Приложения, которых больше нет в App Store: **Сбер, Т-Банк, Альфа-Банк, MAX,
ВКонтакте, Госуслуги, Ozon, Wildberries** — теперь снова доступны на твоём iPhone.

## 🚀 Как это работает

### Три шага — и приложение на экране

1. **Подключи iPhone кабелем к компьютеру**
   Разблокируй телефон и нажми «Доверять» на экране iPhone.

2. **Выбери приложение из каталога**
   Найди нужное в списке или в поиске по названию.

3. **Нажми «Установить» — готово!**
   RuLoad сам подпишет и поставит приложение. Иконка появится на экране.

## ❓ Частые вопросы

<details>
<summary><b>Это безопасно?</b></summary>

Да. RuLoad работает **полностью локально** на твоём компьютере.
Никакие данные (Apple ID, пароли, файлы) не отправляются на серверы.

Исходный код открыт — можно проверить, что программа делает.
</details>

<details>
<summary><b>Нужен ли джейлбрейк?</b></summary>

**Нет.** RuLoad использует официальные инструменты Apple
(libimobiledevice) через USB-кабель. Твой iPhone остаётся в заводском состоянии.
</details>

<details>
<summary><b>Какие приложения можно установить?</b></summary>

Любые IPA-файлы, включая российские приложения:
- Сбер, Т-Банк, Альфа-Банк
- MAX, ВКонтакте
- Госуслуги, Ozon, Wildberries
- Яндекс (Карты, Музыка, Такси)

Свой IPA можно добавить вручную.
</details>

<details>
<summary><b>Нужен ли Apple Developer аккаунт?</b></summary>

**Нет.** Работает с **обычным Apple ID**.

Срок подписи — **7 дней** (ограничение Apple для бесплатных аккаунтов).
После этого нужно **переустановить** приложение через RuLoad.
</details>
