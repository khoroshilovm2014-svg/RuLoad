## 🎯 Что это

**RuLoad** — это бесплатная программа для Windows, которая устанавливает
российские приложения на iPhone через USB-кабель. Просто, быстро, без джейлбрейка.

Приложения, которых больше нет в App Store: **Сбер, Т-Банк, Альфа-Банк, MAX,
ВКонтакте** — теперь снова доступны на твоём iPhone.

---

## ⚠️ Важно: драйверы Apple

**Перед первым запуском RuLoad установи драйверы Apple** — без них
компьютер **не увидит iPhone**.

### Что установить (любой из вариантов):

| Вариант | Ссылка | Размер |
|---|---|---|
| **iTunes** (рекомендуется) | [apple.com/itunes](https://www.apple.com/itunes/) | ~250 МБ |
| **Apple Devices** (из Microsoft Store) | [Microsoft Store](https://apps.microsoft.com/detail/9np83lwlpz9k) | ~50 МБ |

**После установки:**

1. **Перезагрузи компьютер**
2. Подключи iPhone → разреши «Доверять»
3. Запускай RuLoad

**Если iTunes не установлен** — RuLoad **запустится**, но iPhone
**не будет виден** в программе.

## 🚀 Как это работает

### Четыре шага — и приложение на экране

1. **Установи драйверы Apple**
   iTunes или Apple Devices из Microsoft Store. Перезагрузи ПК.

2. **Подключи iPhone кабелем к компьютеру**
   Разблокируй телефон и нажми «Доверять» на экране iPhone.

3. **Выбери приложение из каталога**
   Найди нужное в списке или в поиске по названию.

4. **Нажми «Установить» — готово!**
   RuLoad сам подпишет и поставит приложение. Иконка появится на экране.

## ❓ Частые вопросы

<details>
<summary><b>Это безопасно?</b></summary>

Да. RuLoad работает **полностью локально** на твоём компьютере.
Никакие данные (Apple ID, пароли, файлы) не отправляются на серверы.

Исходный код открыт — можно проверить, что программа делает.
</details>

<details>
<summary><b>Какие драйверы нужны?</b></summary>

**iTunes** или **Apple Devices** из Microsoft Store.
Без них iPhone **не будет виден** в RuLoad.

Скачать iTunes: [apple.com/itunes](https://www.apple.com/itunes/)
</details>

<details>
<summary><b>Нужен ли джейлбрейк?</b></summary>

**Нет.** RuLoad использует официальные инструменты Apple
(libimobiledevice) через USB-кабель. Твой iPhone остаётся в заводском состоянии.
</details>

<details>
<summary><b>Какие приложения можно установить?</b></summary>

Любые IPA-файлы, включая:
- **Банки:** Сбер, Т-Банк, Альфа-Банк
- **Соцсети:** MAX, ВКонтакте

Свой IPA можно добавить вручную.
</details>

<details>
<summary><b>Нужен ли Apple Developer аккаунт?</b></summary>

**Нет.** Работает с **обычным Apple ID**.

Срок подписи — **7 дней** (ограничение Apple для бесплатных аккаунтов).
После этого нужно **переустановить** приложение через RuLoad.
</details>

<details>
<summary><b>Почему приложение удаляется через 7 дней?</b></summary>

Это **ограничение Apple** для бесплатных Apple ID — они выдают
сертификаты только на 7 дней. RuLoad **продлевает** подпись при
следующем запуске — просто открой RuLoad и обнови приложение.

С платным Apple Developer ($99/год) срок — **1 год**.
</details>
